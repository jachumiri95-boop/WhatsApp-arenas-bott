BOT WHATSAPP ARENAS - ARCHIVOS CORREGIDOS

1. En GitHub abre el repositorio WhatsApp-arenas-bott.
2. Reemplaza el archivo index.js de la raíz por este index.js.
3. Reemplaza también package.json por el incluido aquí.
4. Guarda ambos cambios en la rama main.
5. Railway debe tener acceso al repositorio y desplegar el nuevo commit (no uses Redeploy de una imagen antigua).

El bot muestra el QR en los logs de Railway. Luego se vincula desde WhatsApp > Dispositivos vinculados > Vincular dispositivo.
La sesión se guarda en /data/auth_info si el volumen de Railway está montado en /data.
